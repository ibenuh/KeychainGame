# KeychainGame

Game Unity 2D untuk PC. Pemain mengendalikan plush keychain dan menjaga semua keychain tetap menempel di backpack sampai tujuan.

## Status
Tahap ideasi dan GDD. Prototipe Unity belum dimulai.

## Kontrol
- Mouse: mengarahkan tangan plush
- Q: pilih tangan kiri
- E: pilih tangan kanan
- Klik kiri (tahan): menggenggam objek

## Gangguan
- Tangan manusia
- Burung gagak
- Angin

## Mode
- Story
- Endless Run
